# Evaluation handoff (Tanush)

Define the target with Aaron and Arnav before labelling: remaining continuously
open until a ticket is different from being open at the ticket after reopening.
The starter UI is only a demonstration of the former, with synthetic curves.

Build Brier-score and reliability-diagram utilities. Compare forecasts against a
simple baseline fitted on earlier training observations at the same horizons.
Use rolling time splits: training outcomes must be observed before test origins.
Fit calibration only on earlier validation data. Archived current/frozen statuses
do not establish historical closure timing. Do not report demo fixture results as
real forecast performance.
